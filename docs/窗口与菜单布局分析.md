# 窗口与菜单按钮布局分析

## 1. 窗口总体布局（迭代后）

- 当前截图呈现为**双主栏 + 右侧窄工具带**，右侧业务面板处于收起态。
- 横向从左到右依次是：
  - 左侧资源树（项目/目录导航）
  - 中间代码编辑区（主编辑窗口，当前占据主要宽度）
  - 最右垂直工具栏（图标按钮组，承担面板开关入口）
- 宽度比例更接近 `左:中:右工具带 = 1:2.1:0.08`，重心明显向编辑区倾斜。
- 主区两栏均为“标题条 + 内容区”结构，分隔线细、对比弱，视觉连贯而不割裂。

## 2. 左侧窗口（资源树）布局

- 顶部：项目名行（“项目”）作为一级入口。
- 中部：树形目录纵向展开，使用缩进和折叠箭头表达层级。
- 图标与文本左对齐，目录节点按“图标 + 名称”紧凑排列。
- 底部：保留少量空白与末级节点区域，维持滚动延展性。

## 3. 中间窗口（编辑区）布局

- 顶部为文件标签栏，标签横向排列；当前可见两个标签（如 `README.md`、`DataStartResultEntity.java`）。
- 标签栏下方为代码正文区，采用固定行高与行号列。
- 编辑区内容左对齐，正文区域宽阔，右侧留出大量缓冲空间以强化阅读聚焦。

## 4. 右侧区域布局（收起态）

- 未展开独立内容面板（如 Database 主体区不可见）。
- 仅保留最右侧垂直工具带作为入口层，说明右侧功能采用“按需展开”的抽屉/面板机制。
- 与上一版相比，从“常驻第三栏”转为“轻量入口栏”，减少主界面干扰。

## 5. 菜单与按钮布局（仅位置与分组）

### 5.1 顶部按钮分布

- 左侧窗口顶部以“项目名 + 下拉”作为主导航入口，按钮极简。
- 编辑区标题栏右上保留少量状态/菜单按钮（如更多操作），遵循“内容优先、操作次级”。
- 顶部按钮整体数量较上一版更少，视觉噪声更低。

### 5.2 右侧垂直工具栏

- 最右独立窄栏采用纵向按钮堆叠，从上到下排列。
- 每个按钮为居中的图标入口，间距均匀，强调快速切换。
- 顶部图标偏向全局状态/通知，中段图标偏向功能面板切换，形成分段分组。
- 当前激活项用更亮背景/高对比色块突出（蓝色高亮），未激活项弱化显示。

### 5.3 导航与操作层级关系

- 一级导航：左侧资源树、右侧垂直工具栏（负责“去哪”）。
- 二级操作：编辑区标题栏按钮与文件标签切换（负责“做什么”）。
- 三级内容：代码正文区（负责“看结果”）；右侧功能内容改为按需唤起。

## 6. 布局风格特征总结

- **编辑优先**：将空间重点给中间代码区，提升连续编码沉浸感。
- **入口收敛**：右侧复杂功能收敛为窄工具带入口，主界面更干净。
- **层级清晰**：导航（资源树/工具带）与内容（编辑区）边界清楚。
- **一致性强**：图标、间距、对齐方式统一，延续工程类 IDE 的高密度工作流布局。
