# 充电部分接口文档

## 1. 业务信息交换功能

### 1.1 设备认证服务

- 功能：实现充电设备的认证
- 流程：设备发起认证请求，服务平台验证设备身份

### 1.2 业务策略服务（可选）

- 功能：获取充电业务相关策略
- 流程：设备请求业务策略，服务平台返回策略信息

### 1.3 启动充电服务

- 功能：启动充电过程
- 流程：用户请求启动充电，服务平台验证并启动充电

### 1.4 充电监控服务（可选）

- 功能：监控充电过程中的状态
- 流程：实时获取充电状态信息，确保充电安全

### 1.5 充电停止服务（可选）

- 功能：停止充电过程
- 流程：用户请求停止充电，服务平台验证并停止充电

### 1.6 充电订单服务

- 功能：生成和管理充电订单
- 流程：充电完成后生成订单，提供订单查询功能

### 1.7 订单对账服务

- 功能：对充电订单进行对账
- 流程：定期对订单进行核对，确保交易准确

## 2. 业务信息交换接口协议

### 2.1 查询充电站信息

- **接口名称**：query_stations_info
- **接口使用方法**：由基础设施运营商方实现此接口，数据需求方调用
- **输入参数**：
  - 上次查询时间 (LastQueryTime)：格式"yyyy-MM-dd HH:mm:ss"，可以为空，如果不填写，则查询所有的充电站信息
  - 查询页码 (PageNo)：不填写默认为1
  - 每页数量 (PageSize)：不填写默认为10
- **返回值**：
  - 当前页数 (PageNo)：如果查询页码大于页码总数，返回查询页码数
  - 页码总数 (PageCount)：总页数
  - 总记录条数 (ItemSize)：符合条件的电站总数
  - 充电站信息列表 (StationInfos)：类型"StationInfo"，参照 表StationInfo
- **StationInfo**：
  | 名称        | 字段               | 必填 | 类型               | 描述                                                                                             |
  | --------- | ---------------- | -- | ---------------- | ---------------------------------------------------------------------------------------------- |
  | 充电站ID     | StationID        | 是  | 字符串              | 运营商自定义的唯一编码                                                                                    |
  | 运营商ID     | OperatorID       | 是  | 字符串              | 运营商ID                                                                                          |
  | 设备所属方ID   | EquipmentOwnerID | 是  | 字符串              | 设备所属运营平台组织机构代码                                                                                 |
  | 充电站名称     | StationName      | 是  | 字符串              | 充电站名称的描述                                                                                       |
  | 充电站国家代码   | CountryCode      | 是  | 字符串              | 比如CN                                                                                           |
  | 充电站省市辖区编码 | AreaCode         | 是  | 字符串              | 填写内容为参照GB/T2260-2007                                                                           |
  | 详细地址      | Address          | 是  | 字符串              | <br />                                                                                         |
  | 站点电话      | StationTel       | 否  | 字符串              | 能够联系场站工作人员进行协助的联系电话                                                                            |
  | 服务电话      | ServiceTel       | 是  | 字符串              | 平台服务电话，例如400的电话                                                                                |
  | 站点类型      | StationType      | 是  | 整型               | 1：公共；50：个人；100：公交（专用）；101：环卫（专用）；102：物流（专用）；103：出租车（专用）；255：其他                                 |
  | 站点状态      | StationStatus    | 是  | 整型               | 0：未知；1：建设中；5：关闭下线；6：维护中；50：正常使用                                                                |
  | 车位数量      | ParkNums         | 是  | 整型               | 可停放进行充电的车位总数，默认：0未知                                                                            |
  | 经度        | StationLng       | 是  | 浮点型              | GCJ-02坐标系                                                                                      |
  | 纬度        | StationLat       | 是  | 浮点型              | GCJ-02坐标系                                                                                      |
  | 站点引导      | SiteGuide        | 否  | 字符串              | 描述性文字，用于引导车主找到充电车位                                                                             |
  | 建设场所      | Construction     | 是  | 整型               | 1：居民区；2：公共机构；3：企业单位；4：写字楼；5：工业园区；6：交通枢纽；7：大型文体设施；8：城市绿地；9：大型建筑配套停车场；10：路边停车位；11：城际高速服务区；255：其他 |
  | 站点照片      | Pictures         | 否  | 字符串数组            | 充电设备照片、充电车位照片、停车场入口照片                                                                          |
  | 使用车型描述    | MatchCars        | 否  | 字符串              | 描述该站点接受的车大小以及类型，如大巴、物流车、私家乘用车、出租车等                                                             |
  | 车位楼层及数量描述 | ParkInfo         | 否  | 字符串              | 车位楼层以及数量信息                                                                                     |
  | 营业时间      | BusinetHours     | 否  | 字符串              | 营业时间描述                                                                                         |
  | 充电电费率     | ElectricityFee   | 否  | 字符串              | 充电费描述                                                                                          |
  | 服务费率      | ServiceFee       | 否  | 字符串              | 服务费率描述                                                                                         |

  | 设备生产商组织机构代码 | ManufacturingID  | 设备生产商组织机构代码                        | 否  | 字符串              |
  | 设备生产商名称     | ManufacturerName | 设备生产商的名称                           | 否  | 字符串              |

### 2.2 推送设备状态变化

- **接口名称**：notification_stationStatus
- **接口使用方法**：由服务平台调用，第三方实现
- **输入参数**：
  - 充电设备接口状态 (ConnectorStatusInfo)：ConnectorStatusInfo
- **ConnectorStatusInfo**：
  | 名称       | 字段          | 必填 | 类型  | 描述                                              |
  | -------- | ----------- | -- | --- | ----------------------------------------------- |
  | 充电设备接口编码 | ConnectorID | 是  | 字符串 | 充电设备接口编码，同一运营商内唯一                               |
  | 充电设备接口状态 | Status      | 是  | 整型  | 0:离网；1:空闲；2:占用（未充电）；3:占用（充电中）；4:占用（预约锁定）；255:故障 |
  | 车位状态     | ParkStatus  | 否  | 整型  | 0:未知；10:空闲；50:占用                                |
  | 地锁状态     | LockStatus  | 否  | 整型  | 0:未知；10:已解锁；50:已上锁                              |
- **返回值**：
  - 状态 (Status)：0:接受；1:丢弃/忽略，不需要重试
- **示例请求**：
  ```json
  {
    "OperatorID": "23213412324",
    "TimeStamp": "20160701100101",
    "Seq": "0001",
    "Sig": "7130B533249635CD17F113B1D55C2911",
    "Data": {
      "ConnectorStatusInfo": {
        "ConnectorID": "1",
        "Status": 1,
        "ParkStatus": 10,
        "LockStatus": 10
      }
    }
  }
  ```
- **返回**：
  ```json
  {
    "Ret": 0,
    "Msg": "",
    "Sig": "7130B533249635CD17F113B1D55C2911",
    "Data": {
      "Status": 0
    }
  }
  ```

### 2.3 查询设备接口状态

- **接口名称**：query_station_status
- **接口使用方法**：用于批量查询设备实时状态；由基础设施运营商（服务平台）实现，数据需求方（第三方）调用

  | --------- | --------- | ------------- | -- | ------- | ------- |
  | 充电站 ID 列表 | StationIDs | 待查询的充电站 ID 集合 | 是  | 字符串\[] | 数组长度不超过 50 |
- **返回值**（业务数据位于 `Data` 中）：

### 2.4 查询统计信息

- **接口名称**：query_station_stats
- **接口使用方法**：由第三方调用，服务平台实现
- **输入参数**：
  - 充电站ID (StationID)：需要统计的电站
  - 统计开始时间 (StartTime)：格式"yyyy-MM-dd"
  - 统计结束时间 (EndTime)：格式"yyyy-MM-dd"
- **返回值**：
  - 充电站统计信息 (StationStats)：StationStatsInfo 根据查询条件统计出来的充电站的汇总数据，参考 "StationStatsInfo表"
- **StationStatsInfo**：
  | 名称         | 字段                  | 描述                 | 必填 | 类型                    | 长度/范围    |
  | ---------- | ------------------- | ------------------ | -- | --------------------- | -------- |
  | 充电站ID      | StationID           | 站点编号               | 是  | 字符串                   | <=20字符   |
  | 统计的开始时间    | StartTime           | 格式"yyyy-MM-dd"     | 是  | 字符串                   | 10字符     |
  | 统计结束时间     | EndTime             | 格式"yyyy-MM-dd"     | 是  | 字符串                   | 10字符     |
  | 充电站累计电量    | StationElectricity  | 累计电量，单位为kWh,精度为0.1 | 是  | 浮点型                   | 保留小数点后一位 |
  | 充电设备统计信息列表 | EquipmentStatsInfos | 充电站中所有充电设备的统计对象集合  | 是  | EquipmentStatsInfo\[] | <br />   |
- **EquipmentStatsInfo**：
  | 名称           | 字段                   | 描述                 | 必填 | 类型                    | 长度/范围    |
  | ------------ | -------------------- | ------------------ | -- | --------------------- | -------- |
  | 设备编码         | EquipmentID          | 设备唯一编码，对同一运营商，保证唯一 | 是  | 字符串                   | <=23字符   |
  | 充电设备接口累计电量   | EquipmentElectricity | 累计电量，单位为kWh,精度为0.1 | 是  | 浮点型                   | 保留小数点后一位 |
  | 充电设备接口统计信息列表 | ConnectorStatsInfos  | 充设备的所有充电设备接口统计对象集合 | 是  | ConnectorStatsInfo\[] | <br />   |
- **ConnectorStatsInfo**：
  | 名称         | 字段                   | 描述                 | 必填 | 类型  | 长度/范围    |
  | ---------- | -------------------- | ------------------ | -- | --- | -------- |
  | 充电设备接口编码   | ConnectorID          | 充电设备接口编码，同一运营商内唯一  | 是  | 字符串 | <=26字符   |
  | 充电设备接口累计电量 | ConnectorElectricity | 累计电量，单位为kWh,精度为0.1 | 否  | 浮点型 | 保留小数点后一位 |
- **示例请求**：
  ```json
  {
    "OperatorID": "23213412324",
    "TimeStamp": "20160701100101",
    "Seq": "0001",
    "Sig": "7130B533249635CD17F113B1D55C2911",
    "Data": {
      "StationID": "123456",
      "StartTime": "2024-01-01",
      "EndTime": "2024-01-31"
  ```

## 4. 数据传输及安全

### 4.1 消息头

消息头一般需包含**内容类型**和**授权信息（Authorization）**。

**内容类型（Content-Type）**用于标识请求中消息主体的编码方式。本标准中所规范的信息交换内容均采用 JSON 格式，参数信息采用 UTF-8 编码，因此需要配置消息头中的 Content-Type 为：

`application/json; charset=utf-8`

**授权信息（Authorization）**用于证明客户端有权访问某个资源。本标准中所规范的授权信息采用**令牌（Token）**的方式，因此需要在消息头中将 Authorization 配置为：

`Bearer Token`

（其中 `Token` 为通过 `query_token` 等认证接口获取的访问令牌。）

### 4.2 密钥的签发

密钥信息包含 **密钥（SecretKey）**、**消息密钥（DataSecret）**、**消息密钥初始化向量（DataSecretIV）**、**签名密钥（SignKey）**。密钥信息由双方互相交换。**查询类接口**使用玖行方密钥；**推送类接口**使用对接方密钥。

密钥用途如下：

| 密钥 | 用途 |
| --- | --- |
| 密钥（SecretKey） | 认证接口（query_token）校验密钥 |
| 消息密钥（DataSecret） | 参数加密（加密方式见下） |
| 消息密钥初始化向量（DataSecretIV） | 参数加密（加密方式见下） |
| 签名密钥（SignKey） | 参数验签（生成签名方式见下） |

### 4.4 参数签名规范

参数签名采用 **HMAC-MD5** 算法，以 **MD5** 作为散列函数；通过**签名密钥（SigSecret，即 SignKey）**对拼接后的消息进行 HMAC，再形成摘要密文；**参数签名要求大写十六进制表示**。

参数签名顺序按照消息体约定拼接后执行，拼接顺序为：**运营商标识（OperatorID）**、**参数内容（Data）**、**时间戳（TimeStamp）**、**自增序列（Seq）**。

> 说明：下文「HMAC-MD5 参数签名算法」与业界常用的 `HMAC-MD5(K, M)` 定义一致；实现时需保证 `Data` 为与请求中一致的加密后 Base64 字符串（或协议约定的原始串），再与 OperatorID、TimeStamp、Seq 按顺序拼接为消息 `M`。

### 4.5 HMAC-MD5 参数签名算法

```
HMAC(K, M) = H( (K ⊕ opad) | H( (K ⊕ ipad) | M ) )
```

其中：

- `K` 是密钥（签名密钥 / SigSecret），长度可为 64 字节；若小于该长度，在密钥后面用 `0` 补齐；
- `M` 是消息内容；
- `H` 是散列函数（MD5）；
- `opad` 和 `ipad` 分别是由若干个 `0x5c` 和 `0x36` 组成的字符串；
- `⊕` 表示异或运算；
- `|` 表示连接操作。

### 4.6 HMAC-MD5 参数签名流程

a）在签名密钥（SigSecret）后面添加 `0` 来创建一个长 64 字节的字符串（str）；  
b）将上一步生成的字符串（str）与 ipad（`0x36`）做异或运算，形成结果字符串（istr）；  
c）将消息内容 data 附加到第二步的结果字符串（istr）的末尾；  
d）做 MD5 运算于第三步生成的数据流（istr）；  
e）将第一步生成的字符串（str）与 opad（`0x5c`）做异或运算，形成结果字符串（ostr）；  
f）再将第四步的结果附加到第五步的结果字符串（ostr）的末尾；  
g）做 MD5 运算于第六步生成的数据流（ostr），输出最终结果（out）。
