# 玖行桩通信协议 V2.24（协议手册）

> 适用对象：平台联调、协议开发、测试验证。  
> 原始来源：`平台与玖行电桩通信协议V2.24.docx`。  
> 原始解析备份：`docs/玖行桩协议2.24-原始解析备份.md`。

---

## 1. 范围

本文规定玖行运营管理平台与充电桩之间的 TCP 通信协议、命令定义与基本交互约束。

## 2. 规范性说明

- 传输协议：TCP
- 字节序：低字节在前，高字节在后
- 命令码：1 字节（文档显示为 `0X..`）

## 3. 术语与缩略语

- 平台：运营管理平台
- 桩：充电桩设备
- 上行：桩 -> 平台
- 下行：平台 -> 桩

## 4. 帧结构


| 字段     | 类型    | 说明                    |
| ------ | ----- | --------------------- |
| 帧起始    | ASCII | 固定 `JX` (`0x4A 0x58`) |
| 命令     | HEX   | 命令码，见第 5 章            |
| 桩号     | 压缩BCD | 见附录格式表                |
| 数据加密方式 | HEX   | `0x01` 不加密，`0x02` 加密  |
| 数据域长度  | HEX   | `0~65522`             |
| 数据域    | HEX   | 按命令定义                 |
| 校验码    | HEX   | 从命令字节开始异或到本字节前一字节     |

## 6. 结果码（通用）

本版手册以结构化为主，结果码按命令章节细化：

- 成功：通常为 `0`
- 失败：非 `0`，按命令定义
- 失败原因：按对应命令的数据字段定义

## 7. 时序摘要

### 7.1 连接与登录

`0X01 -> 0X02/0x04 -> 0X03 -> 0X04`

### 7.2 对时与心跳

`0X05 -> 0X06 -> 0X07`，并周期性交互 `0X0B / 0X0C`

### 7.3 远端启动充电

`0X1F -> 0X20 -> 0X21 -> 0X22`，过程上报 `0X25`

### 7.4 远端停止充电

`0X26 -> 0X27 -> 0X23 -> 0X24`

- `0X26` 中订单号全 `0x00` 时，桩仅按枪号判断是否可停；非空则按枪号+订单号校验（详见 **8.5**）。

### 7.5 VIN 鉴权

`0X40 -> 0X41 -> 0X21 -> 0X22`，插枪信息可结合 `0X46 / 0X47`

### 7.6 历史订单上传

`0X33 -> 0X34`

### 7.7 本地手动停止后直接上传订单

`0X23 -> 0X24`

## 8. 命令定义（标准协议条目模板）

> 其余命令可按本模板继续扩展。

### 8.1 命令 `0X01` 桩请求连接

- **方向**：上行
- **功能描述**：桩向平台发起连接请求
- **触发条件**：设备上线/重连
- **响应命令**：`0X02`

第一次连接到平台，需在桩内预输入有效密钥及密钥版本。以北京时间为参考，桩请求连接时间标识误差必须在 ±10min 内。  
当平台“请求连接结果 `0X02`”拒绝连接，且“拒绝连接原因”字段值为 1、2、3、4 时，桩应不再重复请求连接。

**请求字段（表-3.1.1 桩请求连接数据）**


| 序号 | 起始 | 定义     | 长度 | 数据类型 | 说明 |
| -- | -- | ------ | -- | ---- | -- |
| 1  | 0  | 时间标识   | 6  | 时间格式 |  |
| 2  | 6  | 密钥版本   | 2  | HEX  | `1~65535` |
| 3  | 8  | 校验密文   | 8  | HEX  | 对字段1、2加密，得到密文 `c[16]`；计算方式：`byte0=c[0]^c[1]`、`byte1=c[2]^c[3]` ... `byte7=c[14]^c[15]` |
| 4  | 16 | 协议版本   | 2  | HEX  | 压缩BCD |


**响应字段（0X02，下行-请求连接结果）**

允许桩连接请求的同时，平台会一同下发供 APP 扫码充电的二维码；每把充电枪都有单独二维码，对应二维码内容为“二维码固定端”字段 + “二维码枪号段 N”。

| 序号 | 起始 | 定义 | 长度 | 数据类型 | 说明 |
| -- | -- | -- | -- | -- | -- |
| 1 | 0 | 时间标识 | 6 | 时间格式 | 报文时间戳 |
| 2 | 6 | 请求结果 | 1 | HEX | `0x01` 允许；`0x02` 不允许 |
| 3 | 7 | 拒绝连接原因 | 1 | HEX | `0` 无；`1` 桩号无效；`2` 密钥版本过期；`3` 校验密文错误；`4` 禁止连接；`5` 平台未准备就绪（如未获取计费模型）；`6` 时差过大（超过10min）；`7` 桩号正在使用 |

> 不允许连接请求时，报文到此结束。

| 序号 | 起始 | 定义 | 长度 | 数据类型 | 说明 |
| -- | -- | -- | -- | -- | -- |
| 4 | 8 | 二维码固定段 | 100 | ASCII | 二维码固定内容段 |
| 5 | 108 | 二维码枪号段数量 | 1 | HEX | `N` |
| 6 | 109 | 二维码枪号段1 | 20 | ASCII | 对应充电枪 1 |
| ... | ... | ... | ... | ... | ... |
| N+5 | 20N+89 | 二维码枪号段 N | 20 | ASCII | 对应充电枪 N |

### 8.4 命令 `0X1F` 平台下发充电命令

- **方向**：下行
- **功能描述**：触发远端启动
- **关联命令**：`0X20`、`0X21`、`0X22`

> **V2.24（本手册）与 `玖行桩协议2.25.md` 的差异提示**  
> - **`0x1F` / `0x20` / `0x21` 的控制参数（定电量等）**：仍为 **`TWO_POINT`（`0.01`）** 量级，与 **`0x23` 报文中「起止充电电量 / 分时段电量」（`FOUR_POINT`，`0.0001kWh`）不是同一字段**，分辨率勿混用。  
> - **`0x21` 序号 15「充电起始电量」**：平台侧 `StartResultHandler224` / `CM21Data.startElect` 与 **`CovertConst.FOUR_POINT`（`0.0001kWh`）** 一致；**V2.24 / V2.25 共用**，勿再按协议手册 PDF 与 `CM21Data` 注释中的 **`0.01kWh`** 误解析。

### 8.5 命令 `0X26` / `0X27` 平台停止充电与桩回复

#### 8.5.1 业务规则（与表 3.9.10 / 3.9.11 一致）

- 平台通过 **`0X26`（下行）** 下发停止充电；桩以 **`0X27`（上行）** 回复是否允许停止。
- **`0X26` 中「充电订单号」32 字节全为 `0x00`**（即空订单号）时：桩侧 **`0X27` 仅按枪号** 判断是否可对当前会话停止；能匹配到该枪上正在充电的会话则 **停止结果=成功**，否则 **停止结果=订单号不一致**（`0x01`）。
- **`0X26` 中订单号非空**（32 字节中存在任一非 `0x00`）时：桩侧 **`0X27` 必须按「枪号 + 订单号」** 与当前充电订单一致才停止；不一致则 **停止结果=订单号不一致**（`0x01`）。

   - **停车费费率、电价费率、服务费费率**：均为 **4 字节 HEX（小端无符号）**，**分辨率 `0.0001`**（与 `0X1F` 内嵌费率段一致）。

#### 8.8.2 `0X23` 上行-最新充电订单（表-3.10.1）

> **协议说明（V2.24）**  
> 桩每 **5 秒** 上送一次，直至收到平台 **下行 `0x24` 回复最新充电订单** 或累计 **10 次**；平台不可达或未应答时，记录写入历史订单。  
> **`0x33` 历史充电订单**：报文体与下表 **字段布局一致**（语义为历史上送），见 **8.8.3**。

> **与 V2.25 的差异（便于对照 `玖行桩协议2.25.md`）**  
> - V2.24 在 **组织机构代码** 之后增加 **充电卡余额 4 字节**（分辨率 `0.01` 元），再为 **VIN**。  
> - **起止充电电量**：V2.24 与 V2.25 均为分辨率 **`0.0001kWh`**；V2.24 各 **4** 字节小端无符号，V2.25 各 **5** 字节小端无符号（低字节在前）。  
> - **时段循环**：V2.24 与 V2.25 均为每段 **计费模型索引 1 字节 + 电量 4 字节小端**，分辨率 **`0.0001kWh`**；仅起止电量字节宽度随版本不同（4 vs 5）。  
> - **电池 SN**：V2.24 为 **27** 字节 ASCII（与平台 `CM23Data224.snCode` 一致）；V2.25 常见实现为 **17** 字节（以 `玖行桩协议2.25.md` 为准）。

> **工程约定（本模拟器，已与平台解析对齐）**  
> - **时间类 6 字节字段**：每字段 1 字节，按 **十进制数值直接写入字节值**（如年 `26` → `0x1A`），与表1.6 常见实桩行为一致；**不使用 BCD**。  
> - **定时启动时间**：与 **`0x1F` 报文内该字段原始 6 字节** 一致回显；立即启动时可为全 `0`。  
> - **计费模型选择 / 计费模型版本**：与 **远端启动 `0x1F` 下发** 的 `billingModelSelect` 及 **当时桩内生效的计费模型版本**（与 `0x37` 下发版本一致）一致。  
> - **电能费用 / 服务费费用 / 停车费费用**：各 4 字节小端，分辨率 **`0.01` 元**（整数单位为分）；停车费无则填 `0`。  
> - **起止电量**：各 **4** 字节小端无符号整数，分辨率 **`0.0001kWh`**（与 Java `CovertConst.FOUR_POINT` / `OrderHandler224` 一致）；起电一般为 `0`，止电为本次累计充电量。  
> - **时段循环**：`N` 为 `1~20`；每段 **索引 1 字节 + 电量 4 字节**；段电量分辨率 **`0.0001kWh`**；业务上与 `0x25` 过程上报分段对应（模拟器按 kWh 折算为 wire 整数并钳位到 `0~429496.7295kWh` 理论上限）。  
> - **控制参数（`modeValue`）**：与 **起止/分时段电量** 不是同一量纲。定金额/定电量等分支在平台侧按 `OrderHandler224` 使用 `TWO_POINT`（`0.01`）换算金额或电量上限；**定电量充** 下整数单位为 **`0.01kWh/bit`**。定时长按秒换算、设定 SOC 等为整数百分比。
