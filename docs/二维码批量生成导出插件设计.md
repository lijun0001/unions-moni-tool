# 二维码批量生成导出插件设计文档

> 文档目标：定义「二维码批量生成导出」插件的功能范围、Excel 契约、交互与实现方案，作为开发与评审基线。  
> 适用宿主：Unions Moni Tool（Electron + Vue 3 + TypeScript 插件体系）。

---

## 0. 宿主规范与技能约束（强制）

本设计为宿主产品内插件，必须遵循 `docs/PROJECT_FRAMEWORK.md`：

- 插件契约：`ProtocolSimulatorPlugin`（`meta` / `homeCard` / `MainView`），内置静态注册于 `plugin-loader`。
- 视觉与主题：使用宿主 CSS 变量（`--um-*`）与 Element Plus 深色策略，不另起主题体系。
- 文件读写：通过 `window.unions` 预加载白名单 IPC（Excel 二进制读/写、对话框），禁止渲染进程直接 `nodeIntegration`。
- 若本文与宿主框架冲突，以宿主框架为准。

涉及界面实现时对照 `.cursor/skills/impeccable`：克制动效、避免廉价装饰（粗色条、渐变文字等）。

## 1. 插件定位与目标

**插件 ID**：`qr-batch-export`  
**展示名**：二维码批量生成导出

面向测试/运营人员，从 Excel 批量导入待编码字符串，生成带可选底部说明文字的二维码图片，在界面中预览并导出含图片的 Excel。

### 1.1 核心能力

| 能力 | 说明 |
|------|------|
| 导入 Excel | 解析模板列，校验必填「二维码信息」 |
| 批量生成 | 按行生成二维码图（可选底部文字） |
| 结果列表 | 展示字符串、描述、缩略图；点击缩略图放大 |
| 导出结果 Excel | 含嵌入 PNG 的结果表 |
| 导出模板 Excel | 仅表头与示例行，供用户填写 |

### 1.2 二维码解析（Tab）

- **二维码解析** Tab：点击/拖拽/粘贴图片，在区域内展示解码字符串，支持复制；「前往生码」切换至生成 Tab，「继续解码」重置上传区。
- 多图批量时展示最后一次成功结果并提示成功数量。

### 1.3 非目标

- 二维码样式美化（Logo、圆角、彩色）
- 解析历史持久化与「最近解码」列表（后续可扩展）

## 2. Excel 数据契约

### 2.1 导入/模板列（首行表头）

| 列名（固定） | 必填 | 说明 |
|--------------|------|------|
| 二维码信息 | 是 | 写入二维码的字符串（URL、文本、业务码等） |
| 文字描述 | 否 | 显示在二维码**下方**；空则**不预留**文字区域，图片高度仅为码区 |

表头必须精确匹配上述中文列名（首版不做多别名，降低歧义）。模板第二行可提供示例数据。

### 2.2 导出结果列

| 列名 | 说明 |
|------|------|
| 二维码信息 | 与导入一致 |
| 文字描述 | 与导入一致（可为空） |
| 二维码 | 嵌入 PNG（与界面生成图一致） |

### 2.3 校验规则

- 空文件、无工作表、表头缺失 → 阻断并提示。
- 「二维码信息」为空的行：生成阶段跳过或在结果中标记错误（首版：**跳过并在消息中汇总跳过行数**）。
- 单次建议上限 **2000 行**（超出提示，仍可继续由用户确认）。

## 3. 二维码图像规格

### 3.1 像素尺寸选项

用户可在生成前选择输出图**宽度（正方形边长，像素）**：

| 选项 | 值 (px) | 默认 |
|------|---------|------|
| 小 | 128 | |
| 中 | 256 | ✓ |
| 大 | 384 | |
| 特大 | 512 | |

码区使用 `qrcode` 库生成，纠错级别 `M`，quiet zone `margin: 2`。

### 3.2 含/不含文字描述

- **无描述**：输出正方形图，边长 = 所选像素尺寸。
- **有描述**：在码图下方增加内边距 + 单行或多行文字（超长自动换行，最大宽度 = 码宽）；总画布高度 = 码高 + 文字区（动态计算，不预留空白）。

字体：系统无衬线栈，`12px` 基准，随尺寸同比缩放（`fontSize = max(10, round(size * 0.047))`）。

## 4. 交互与信息架构

### 4.1 页面结构（双 Tab）

- **二维码生成**：工具栏（导入 Excel、尺寸、生成）+ 列表区（显示「共生成 N 个」；有数据时列表区内显示品牌色「导出结果 Excel」按钮）。
- **二维码解析**：虚线框上传区；解码成功后同区域展示结果与复制、前往生码、继续解码。

### 4.2 交互细节

- **导入**：系统文件对话框，筛选 `.xlsx`。
- **导出模板**：保存对话框，默认文件名 `二维码批量导入模板.xlsx`。
- **生成**：清空上次结果后按当前导入数据与尺寸选项重算；生成中按钮 loading。
- **预览**：点击表格「二维码」列缩略图 → `el-dialog` 展示大图 + 完整字符串。
- **导出结果**：保存 `.xlsx`，列宽与行高适配嵌入图。

样式：卡片容器 `bg-[var(--um-surface)]`、`border-[var(--um-border)]`、主按钮 `bg-[var(--um-brand)]`，与 `ImportView` / 插件壳一致。

## 5. 技术实现

### 5.1 模块划分

```
src/renderer/plugins/qr-batch-export/
  index.ts              # 插件导出
  QrBatchMainView.vue   # 主界面
  types.ts              # 行类型、尺寸枚举
  qr-image.ts           # Canvas 合成二维码图 → data URL / Uint8Array
  qr-excel.ts           # 模板/导入/导出（exceljs）
```

### 5.2 依赖

- 已有：`qrcode`
- 新增：`exceljs`（读写在渲染进程完成，经 IPC 获取/写入文件二进制）

### 5.3 IPC 扩展（主进程）

| Channel | 说明 |
|---------|------|
| `dialog:openExcelFile` | 打开 `.xlsx` |
| `fs:readBinaryFile` | 读文件为 `Uint8Array`（base64 传输） |
| `dialog:saveBinaryFile` | 保存对话框 + 写入二进制（base64） |

### 5.4 内置注册

- `src/renderer/services/plugin-loader.ts` 增加 `qr-batch-export` 分支。
- `src/renderer/stores/plugins.ts` 增加 `BUILTIN_QR_RECORD`。
- `plugins/qr-batch-export/manifest.json` 占位（与 CEC/JX 一致，实际走内置）。
